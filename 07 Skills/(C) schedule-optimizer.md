# Skill: Schedule Optimizer (Module 4 — Weekly Optimizer)

Cross-references your standard weekly schedule, live Google Calendar, open Notion tasks, and unread Gmail to generate a fully optimized, time-blocked schedule for today and the week ahead. This is your daily execution plan — not a suggestion list.

---

## When to Run

- **Daily** — every morning as part of the full briefing
- **Mondays** — runs in extended mode: full weekly plan, not just today
- **On demand** — say "Run schedule optimizer", "Optimize my schedule", or "Run Module 4"

---

## How to Run

Execute these pulls in sequence. Each step feeds into the final output.

### Step 1 — Load the Standard Weekly Schedule

Read the file at `03 Projects/Assistant/00 Inputs/Weekly Schedule Template.md`.

Extract for today's day of week:
- Wake time, gym block (if applicable), deep work blocks (Block 1 + Block 2), lunch, wind-down, lights out
- Block 1 focus (creation / editing / production)
- Block 2 focus (ops / admin / comms / meetings)
- Any day-specific rules (e.g., Tue/Thu = client calls 1–3 PM, Mon/Wed/Fri = gym 6:15 AM)

This is the **base template**. Everything else overlays on top of it.

---

### Step 2 — Pull Live Calendar

Use `list_events`:
- `calendarId`: `ayden@escalation-media.com`
- `startTime`: today 00:00 (America/Toronto)
- `endTime`: today + 7 days 23:59 (America/Toronto)
- `timezone`: `America/Toronto`

For each event, capture: title, start time, end time, attendees, location/link, RSVP status.

Flag any event that conflicts with the base template rules:
- Meeting before noon → 🚩 Violates "No Meetings Before Noon" rule
- Event in Block 1 (creation time) → 🚩 Conflict — protect Block 1?
- Unaccepted invite → ⚠️ Needs response
- Event with no prep time buffered before it → ⚠️ Add 15-min prep block

---

### Step 3 — Pull Open Notion Tasks

Use `notion-search`:
- `data_source_url`: `collection://2f55b015-d19d-8196-b261-000b599b76a4`
- `query`: "tasks open to-do doing inbox waiting"
- `page_size`: 25

For each task, use `notion-fetch` to get: Status, Priority, Due Date, Notes, Tag.

Filter out Status = **Done**.

Score each task for scheduling urgency:

| Signal | Points |
|--------|--------|
| Priority = High | +3 |
| Due = today or overdue | +3 |
| Due = this week | +2 |
| Tied to a calendar event today/this week | +2 |
| Tied to revenue or client delivery | +2 |
| Status = Doing | +1 |
| Status = Waiting | +1 |

Sort all tasks by score (highest first). This determines Block assignment.

---

### Step 4 — Pull Unread Emails

Use `search_threads`:
- `query`: `is:unread newer_than:2d -in:draft`
- Pull subject, sender, and snippet for each thread

Classify each email:
- **Action required** — a reply is needed, a decision is being waited on, or a commitment was made
- **FYI only** — update, receipt, notification — no action needed
- **Spam / low signal** — newsletters, promos — ignore

From action-required emails, extract any implied tasks that don't already exist in Notion. These become **injected tasks** for today's schedule if urgent.

---

### Step 5 — Build the Optimized Schedule

Now synthesize everything into a time-blocked day plan.

**Rules (non-negotiable — always enforce these):**
1. Block 1 = creation only. No email, no client comms, no meetings.
2. Gym slots (Mon/Wed/Fri 6:15 AM) are locked. Don't schedule anything over them.
3. No meetings before noon.
4. Lunch is not a working lunch — it's a real break.
5. All client/videographer calls → Tue/Thu 1–3 PM window only.
6. ALVION + networking → late Block 2 (3–5 PM). After production work.
7. Editor briefs → end of Block 2 (4–5 PM). Not during Block 1.
8. Screens off 9 PM. In bed 10 PM. Hard cutoff.

**Block 1 (morning deep work) — assign top-scoring tasks that require focus, creation, or production.**
- Use the day's Block 1 focus from the schedule template as the anchor (e.g., Wed = video editing + production pipeline)
- Slot the top 1–2 tasks here. No more than 2 unless they're very small.
- If a calendar event is already in Block 1 → flag it, suggest rescheduling it to Block 2 or another day

**Block 2 (afternoon ops/admin) — assign everything else.**
- Client comms, emails requiring replies, Notion admin, hiring, outreach
- Slot meetings from the calendar into their confirmed times
- Injected tasks from emails go here unless they're urgent deep-work items

**Buffer rule:** Add a 15-min buffer before any meeting or call. Mark it as prep time.
