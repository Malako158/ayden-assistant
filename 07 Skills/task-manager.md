# Skill: Task Manager (Module 4)

Pulls all open tasks from Notion, cross-references against calendar and emails, and surfaces the single most important task today plus a full prioritized breakdown.

---

## When to Run

- **Daily** — run every morning as part of the full briefing
- **On demand** — say "Run Module 4" or "Run task briefing"

---

## How to Run

1. Fetch all tasks from the Notion Tasks database using `notion-search`:
   - `data_source_url`: `collection://2f55b015-d19d-8196-b261-000b599b76a4`
   - `query`: "tasks open to-do doing inbox waiting"
   - `page_size`: 25
2. For any task returned, fetch individual page details via `notion-fetch` to get Status, Priority, Due Date, and Notes fields
3. Filter out tasks with Status = **Done** — don't surface them
4. Pull today's calendar events via `list_events` (calendarId: `ayden@escalation-media.com`, today only) for cross-reference
5. Pull recent unread emails via `search_threads` (query: `is:unread newer_than:2d -in:draft`) for cross-reference
6. Apply Priority Logic (see below)
7. Generate the Task Briefing output (see format below)
8. Save to `03 Projects/Assistant/04 Task Manager/(C) Task Briefing — YYYY-MM-DD.md`

---

## Priority Logic

When determining the #1 task of the day, score each open task against:

| Signal | Weight |
|--------|--------|
| Priority = High in Notion | +3 |
| Due Date = today or overdue | +3 |
| Mentioned in recent email (urgent tone, pending action) | +2 |
| Related to calendar event today or this week | +2 |
| Ties directly to revenue or client delivery | +2 |
| Status = Doing (already in progress) | +1 |
| Status = Waiting (blocked — needs a decision or action to unblock) | +1 |
| Status = Inbox / To-Do (not started) | 0 |

The task with the highest combined score is **#1 today**. If tied, prefer the one tied to revenue or a named client.

---

## Task Classification

After scoring, bucket all open tasks into three tiers:

| Tier | Criteria |
|------|----------|
| 🔴 **Do Today** | High priority, due today/overdue, or directly tied to a calendar event today |
| 🟡 **This Week** | Medium priority, due this week, or cross-referenced with upcoming events |
| ⚪ **Backlog** | Low priority, no due date, no email/calendar signal |

---

## Cross-Reference Rules

| Signal | Action |
|--------|--------|
| Task matches a calendar event today | Promote to 🔴 Do Today |
| Task mentioned in unread email (pending, urgent) | Promote one tier |
| Task has a due date in the past | Flag as ⚠️ Overdue |
| Email implies task is done (e.g., contract signed) | Flag as ✅ Likely done — verify in Notion |
| Task has Status = Waiting | Note what it's waiting on if known |
