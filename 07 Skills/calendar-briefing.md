# Skill: Calendar Briefing (Module 3)

Generates a daily or weekly calendar briefing from Google Calendar, cross-referenced against recent emails to flag missing events.

---

## When to Run

- **Daily** — run every morning as part of the full briefing
- **Monday** — runs the extended Weekly Report instead of the standard daily format
- **On demand** — say "Run calendar briefing" or "What's on my calendar?"

---

## How to Run

### Daily Briefing (Tue–Sun)
1. Pull calendar events for today using `list_events` — `startTime`: today 00:00, `endTime`: today 23:59, calendarId: `ayden@escalation-media.com`, timezone: `America/Toronto`
2. Pull calendar events for the next 7 days — same calendar, `startTime`: today, `endTime`: today + 7 days
3. Pull unread emails from Gmail (last 48 hours) using `search_threads` — query: `is:unread newer_than:2d -in:draft`
4. Cross-reference emails against calendar (see Cross-Reference Rules below)
5. Generate the Daily Briefing output (see format below)
6. Save to `03 Projects/Assistant/03 Calendar/(C) Calendar Briefing — YYYY-MM-DD.md`

### Weekly Report (Mondays only)
1. Pull calendar events for the full week ahead (Mon–Sun) — `startTime`: today, `endTime`: today + 7 days
2. Pull emails from the past 7 days — query: `newer_than:7d -in:draft`
3. Cross-reference emails against calendar
4. Generate the Weekly Report output (see format below)
5. Save to `03 Projects/Assistant/03 Calendar/(C) Weekly Report — YYYY-MM-DD.md`

---

## Cross-Reference Rules

When scanning emails, flag anything that implies a calendar commitment but has no matching event:

| Email signal | Flag as |
|---|---|
| "let's meet", "scheduled for", "confirmed for [date/time]" | ⚠️ Missing event — add to calendar? |
| Signed contract / agreement | ⚠️ Kickoff/onboarding call needed? |
| "see you [day]", "talk [day]" | ⚠️ Verbal commitment — add to calendar? |
| Calendar invite already in calendar | ✅ Already covered — skip |
| Newsletter, promotion, automated notification | Skip entirely |

Only flag things in the **future**. Ignore past events.
