# Commands & Skills

Quick reference for all available skills and commands in the Assistant project.

## Skills (in 07 Skills/)

| Skill | File | Trigger |
|-------|------|---------|
| Calendar Briefing | `07 Skills/calendar-briefing.md` | "Run calendar briefing" or "What's on my calendar?" |
| Email Triage | *(no skill file yet — runs via Module 1 directly)* | "Run email triage" |
| Task Manager | `07 Skills/task-manager.md` | "Run Module 3" or "Run task briefing" |
| Schedule Optimizer | `07 Skills/(C) schedule-optimizer.md` | "Run schedule optimizer", "Optimize my schedule", or "Run Module 4" |

## Commands

| Command | What it does |
|---------|-------------|
| "Run calendar briefing" | Runs Module 2 — daily format (Tue–Sun) or weekly report (Mondays) |
| "Run email triage" | Runs Module 1 — pulls unread Gmail, classifies, flags, suggests replies |
| "Run Module 3" | Runs Task Manager |
| "Run Module 4" | Runs Schedule Optimizer — cross-references schedule, calendar, tasks, and email into a time-blocked day plan |
| "Optimize my schedule" | Same as Run Module 4 |
| "Run full briefing" | Runs all available modules in sequence |
